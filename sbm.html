二次方程式

二次方程式は「xの2乗が入った方程式」のこと。解き方は主に3つ：因数分解、解の公式、平方完成。 これをマスターすれば芝浦工大の入試問題もバッチリ！

📐 二次方程式の重要公式

標準形: ax² + bx + c = 0
解の公式: x = (-b ± √(b² - 4ac)) / (2a)
💡 「マイナスビー、プラマイ、ルート、ビー2乗マイナス4AC、分の、2A」
判別式: D = b² - 4ac
D > 0: 異なる2つの実数解 / D = 0: 重解 / D < 0: 実数解なし
解と係数の関係: α + β = -b/a, αβ = c/a
因数分解型: (x - α)(x - β) = 0 → x = α または x = β
Problem 1 ★☆☆ 基礎
次の二次方程式を因数分解を使って解け。
x² - 5x + 6 = 0
🍎 身近な例で理解しよう
りんごが何個かあります。それを5個減らして、残りを6個にしたい。 でも、掛け算で考えると... これが二次方程式の世界！
🎯 解法1: 因数分解で解く（一番速い！）
ステップ1: 因数分解する
x² - 5x + 6 = (x - 2)(x - 3) = 0
👶 小学生向け説明
「掛けて6、足して-5になる2つの数は何？」と考えます。
-2 × -3 = 6（掛けて6）
-2 + (-3) = -5（足して-5）
だから -2 と -3 です！
ステップ2: それぞれを0にする
x - 2 = 0 または x - 3 = 0
ステップ3: 解を求める
x = 2 または x = 3
🧠 記憶のコツ
「0になるには？」→「掛けられる数のどちらかが0になればいい！」 これは「0 × 何か = 0」という小学校で習ったルールと同じです。
🎯 解法2: 解の公式を使う（確実！）
a = 1, b = -5, c = 6 を確認
判別式を計算: D = b² - 4ac = (-5)² - 4(1)(6) = 25 - 24 = 1
👶 判別式って何？
判別式は「答えが何個あるか」を教えてくれる数です。
D = 1 > 0 だから、答えは2個あります！
解の公式に代入:
x = (5 ± √1) / 2 = (5 ± 1) / 2
x = (5 + 1) / 2 = 3
x = (5 - 1) / 2 = 2
🎯 解法3: グラフで確認（視覚的理解！）
y = x² - 5x + 6 のグラフを想像する
このグラフがx軸と交わる点が解になる
👁️ 放物線（U字型のグラフ）がx軸を横切る2つの点が x = 2 と x = 3 です。 紙に描いてみると、目で見て理解できます！
⚠️ よくある間違い
× x² - 5x + 6 = 0 から x = 6/5 と計算してしまう
→ これは一次方程式の解き方！二次方程式は因数分解か解の公式を使おう。
✓ 答え: x = 2, 3
Problem 2 ★★☆ 標準
次の二次方程式を解け。
x² + 6x + 9 = 0
🎂 ケーキの分け方
正方形のケーキの1辺の長さをxとすると、面積は x² です。 周りに x を6個、角に9個の飾りをつける... これが完全平方式！
🎯 解法1: 完全平方式として因数分解
x² + 6x + 9 を見ると...
これは (x + 3)² の形になっている！
👶 完全平方式の見分け方
真ん中の数(6)が、2 × 何か × 3 の形になっているかチェック。
6 = 2 × 1 × 3 ✓
最後の数(9)が、3 × 3 の形になっているかチェック。
9 = 3² ✓
両方当てはまれば完全平方式です！
(x + 3)² = 0
両辺の平方根を取る: x + 3 = 0
x = -3
🧠 重解の意味
同じ答えが2回出てくることを「重解」といいます。 グラフでいうと、放物線がx軸にピッタリ接している状態です！
🎯 解法2: 解の公式で確認
a = 1, b = 6, c = 9
判別式: D = 6² - 4(1)(9) = 36 - 36 = 0
👶 D = 0 の意味
判別式が0ということは、答えが1個だけ（重解）という意味です！
x = (-6 ± √0) / 2 = -6 / 2 = -3
🎯 解法3: 平方完成
x² + 6x + 9 = 0
(x + 3)² = 0
x + 3 = 0 → x = -3
✓ 答え: x = -3 (重解)
Problem 3 ★★☆ 標準
次の二次方程式を解け。
2x² - 7x + 3 = 0
🚗 車の速度問題
時速xkmで走る車が、ある距離を走るのにかかる時間を計算すると、 こういう二次方程式になることがあります！
🎯 解法1: たすきがけで因数分解
たすきがけの手順:
① 2x² を作る: 2x と x
② 3 を作る: -1 と -3
③ クロスして確認: 2x×(-3) + x×(-1) = -6x - x = -7x ✓
👶 たすきがけって何？
たすきがけは、因数分解の魔法のテクニック！
    2x  -1   → 2x × (-3) = -6x
     ×  ×
     x  -3   → x × (-1) = -x
                合計: -7x ✓
クロスした答えを足して、真ん中の数(-7x)になればOK！
(2x - 1)(x - 3) = 0
2x - 1 = 0 または x - 3 = 0
x = 1/2 または x = 3
🎯 解法2: 解の公式（確実な方法）
a = 2, b = -7, c = 3
D = (-7)² - 4(2)(3) = 49 - 24 = 25
x = (7 ± √25) / (2×2) = (7 ± 5) / 4
x = (7 + 5) / 4 = 12/4 = 3
x = (7 - 5) / 4 = 2/4 = 1/2
🧠 計算ミス防止法
解の公式を使うときは、±(プラスマイナス)を忘れずに！ 先に+の答え、次に-の答えを書くクセをつけよう。
🎯 解法3: 検算で確かめる
x = 3 を元の式に代入:
2(3)² - 7(3) + 3 = 18 - 21 + 3 = 0 ✓
x = 1/2 を元の式に代入:
2(1/2)² - 7(1/2) + 3 = 2(1/4) - 7/2 + 3
= 1/2 - 7/2 + 6/2 = 0 ✓
👶 検算の大切さ
答えを元の式に戻して0になるか確かめよう！ これがテストで満点を取る秘訣です。
✓ 答え: x = 3, 1/2
Problem 4 ★★★ 応用
次の二次方程式を解け。
x² - 2x - 5 = 0
📱 スマホの画面サイズ
画面の縦の長さがxcmのとき、対角線の長さを計算すると こういう方程式が出てきます！（ピタゴラスの定理を使うと）
🎯 解法1: 解の公式を使う
因数分解できないので解の公式を使う！
👶 因数分解できない？
「掛けて-5、足して-2になる整数」がないので、 因数分解できません。こういう時は解の公式の出番！
a = 1, b = -2, c = -5
D = (-2)² - 4(1)(-5) = 4 + 20 = 24
x = (2 ± √24) / 2
√24 を簡単にする: √24 = √(4×6) = 2√6
👶 √(ルート)の簡単化
√24 の中の24を分解します:
24 = 4 × 6 = 2² × 6
2²は√の外に出せるので、√24 = 2√6 になります！
x = (2 ± 2√6) / 2 = 1 ± √6
🧠 √の簡単化のコツ
√の中を「完全平方数×何か」の形に分解する！
完全平方数: 1, 4, 9, 16, 25, 36...
🎯 解法2: 平方完成で解く
x² - 2x - 5 = 0
x² - 2x = 5
両辺に1を加える: x² - 2x + 1 = 5 + 1
👶 なぜ1を加える？
x² - 2x + 1 は (x - 1)² になる完全平方式だから！
真ん中の係数(-2)を2で割って2乗: (-2÷2)² = 1
(x - 1)² = 6
x - 1 = ±√6
x = 1 ± √6
🎯 解法3: 近似値を計算
√6 ≈ 2.449（電卓で計算）
x = 1 + √6 ≈ 1 + 2.449 = 3.449
x = 1 - √6 ≈ 1 - 2.449 = -1.449
👁️ グラフを描くと、x軸との交点が約3.4と約-1.4の位置にあります！
✓ 答え: x = 1 ± √6
Problem 5 ★★☆ 標準
次の二次方程式を解け。
x² + 4x + 5 = 0
🎯 解法: 判別式で確認
a = 1, b = 4, c = 5
D = 4² - 4(1)(5) = 16 - 20 = -4
👶 D < 0 の意味
判別式がマイナスということは、実数の解が存在しません！
グラフで言うと、放物線がx軸と交わらない状態です。
🧠 覚え方
D(判別式)の値:
• D > 0: 異なる2つの実数解
• D = 0: 重解（1つの解）
• D < 0: 実数解なし
✓ 答え: 実数解なし
Problem 6 ★★★ 応用
x² - 6x + k = 0 が重解を持つとき、定数kの値を求めよ。
x² - 6x + k = 0 (重解)
🎯 解法: 判別式 = 0
重解を持つ条件: D = 0
D = (-6)² - 4(1)(k) = 0
36 - 4k = 0
4k = 36
k = 9
👶 重解の条件
重解 = グラフがx軸に接する = 判別式が0
だから D = 0 の式を作って解くだけ！
✓ 答え: k = 9
Problem 7 ★★☆ 標準
次の二次方程式を解け。
(x - 1)(x + 3) = 5
🎯 解法: まず展開する
左辺を展開: x² + 2x - 3 = 5
移項: x² + 2x - 8 = 0
因数分解: (x + 4)(x - 2) = 0
x = -4, 2

→ 右辺が0でないと、この方法は使えません！

Problem 8 ★★★ 応用
解が x = 2, -5 である二次方程式を作れ。
🎯 解法: 因数定理を使う
解が α, β なら (x - α)(x - β) = 0
(x - 2)(x - (-5)) = 0
(x - 2)(x + 5) = 0
展開: x² + 3x - 10 = 0
✓ 答え: x² + 3x - 10 = 0
Problem 9 ★★★ 応用
x² - 4x + 1 = 0 の2つの解を α, β とするとき、α² + β² の値を求めよ。
🎯 解法: 解と係数の関係を使う
α + β = 4, αβ = 1
α² + β² = (α + β)² - 2αβ
= 4² - 2(1) = 16 - 2 = 14
👶 公式の導き方
(α + β)² = α² + 2αβ + β²
両辺から 2αβ を引くと:
α² + β² = (α + β)² - 2αβ
✓ 答え: 14
Problem 10 ★★★ 発展
長方形の縦の長さが横より3cm短く、面積が54cm²のとき、横の長さを求めよ。
📐 実際の文章題
これは芝浦工大でよく出る「文章から方程式を作る」問題です！
🎯 解法: 文章から式を作る
横の長さを x cm とする
縦の長さは (x - 3) cm
面積の式: x(x - 3) = 54
展開: x² - 3x = 54
x² - 3x - 54 = 0
因数分解: (x - 9)(x + 6) = 0
x = 9, -6
長さは正なので x = 9 cm
👶 答えの選び方
長さはマイナスになりえないので、x = -6 は不適切。
だから x = 9 cm が答えです！
✓ 答え: 9 cm

連立方程式

2つ以上の方程式を同時に満たすxとyを見つける問題。加減法と代入法をマスターしよう！

📐 連立方程式の解法

加減法: 2つの式を足したり引いたりして、1つの文字を消去
代入法: 1つの式から文字を表して、もう1つの式に代入
基本形: { ax + by = c, dx + ey = f }
Problem 1 ★☆☆ 基礎
次の連立方程式を解け。
{ x + y = 5
{ x - y = 1
🍎🍊 りんごとオレンジ
りんご x個とオレンジ y個、合わせて5個。 りんごがオレンジより1個多い。何個ずつ？
🎯 解法1: 加減法（一番簡単！）
ステップ1: 2つの式を足す
(x + y) + (x - y) = 5 + 1
2x = 6
x = 3
👶 なぜ足すの？
+y と -y が打ち消し合って消えるから！
(x + y) + (x - y) = x + y + x - y = 2x
ステップ2: x = 3 を最初の式に代入
3 + y = 5
y = 2
🧠 検算の習慣
x = 3, y = 2 を両方の式に代入して確認しよう！
3 + 2 = 5 ✓
3 - 2 = 1 ✓
🎯 解法2: 代入法
1つ目の式から: y = 5 - x
2つ目の式に代入: x - (5 - x) = 1
x - 5 + x = 1
2x = 6 → x = 3
y = 5 - 3 = 2
✓ 答え: x = 3, y = 2
Problem 2 ★★☆ 標準
次の連立方程式を解け。
{ 2x + 3y = 13
{ 3x - y = 3
💰 買い物の問題
ペン2本とノート3冊で1300円。 ペン3本とノート(-1冊返品)で300円。 それぞれの値段は？
🎯 解法: yを消去する加減法
2つ目の式を3倍する（yの係数を揃える）
3(3x - y) = 3(3)
9x - 3y = 9
👶 なぜ3倍？
1つ目の式の 3y と、2つ目の式の -y を揃えたい。
-y を -3y にすれば、3y + (-3y) = 0 で消える！
2つの式を足す:
(2x + 3y) + (9x - 3y) = 13 + 9
11x = 22
x = 2
x = 2 を 3x - y = 3 に代入:
3(2) - y = 3
6 - y = 3
y = 3
✓ 答え: x = 2, y = 3
Problem 3 ★★☆ 標準
次の連立方程式を解け。
{ 5x - 2y = 11
{ 3x + 4y = 1
🎯 解法: 係数を揃えて加減法
1つ目の式を2倍: 10x - 4y = 22
足し算: (10x - 4y) + (3x + 4y) = 22 + 1
13x = 23 → x = 23/13
代入して y = -8/13
✓ 答え: x = 23/13, y = -8/13
