Grammar Notes for Eiken Pre-1
01

a と s、迷ったら裸で出さない

数えられる名詞は a / an / the をつけるか、複数形 にする。裸はNG。
×I eat apple.
○I eat an apple.
○I eat apples.

food, water, money, information, advice は数えない。複数形にもしない。

×a lot of foods
○a lot of food
02

一般論を言うときは 複数形

「〜というものは」と一般化するときは複数形が自然。
×Country needs food.
○Countries need food.
○in many countries

country / countries、child / children、person / people。 -y は -ies に、-f は -ves に。

03

動詞は文に必ず 一つ、二つはダメ

be動詞 (is/are) と一般動詞 (eat, go) は同居しない。
×Japan is import food.
○Japan imports food.
×Japan a country.
○Japan is a country.

主語が he / she / it / 単数 → is、動詞に s。 we / they / 複数 → are、動詞は原形。

04

原形か -ing かは「前」で決まる

前形
to原形 (to eat)
can / will / should原形 (can eat)
前置詞 (by, for, of)-ing (by eating)
be動詞-ing 進行形 / 過去分詞 受身
○I want to eat.
○good at cooking
○By producing more food
05

to不定詞 の3つの顔

to + 動詞の原形。3つの使い方を覚える。
用法意味
名詞的〜すること
形容詞的〜するための
副詞的〜するために
○I want to study English.（こと）
○a way to solve it（ための）
○I went there to meet him.（ために）

「〜するために」を強調したいときは in order to / so as to。

06

so 〜 that ⇄ too 〜 to

「〜すぎて〜できない」の言い換え。準1で頻出。
too + 形容詞 + to V ≒ so + 形容詞 + that S can't V
He is too busy to sleep. ≒ He is so busy that he can't sleep.

逆方向「〜できるほど〜だ」は enough to。

形容詞 + enough + to V
○He is old enough to drive.
07

by と for、似てるけど違う

語意味
by方法、手段
for目的、対象
from出所、起点
○solve it by producing food（方法）
○food for children（対象）
○food from abroad（出所）
コツ。by のあとは 動名詞 (-ing)。to のあとは 原形。混ぜない。
08

カンマは 4箇所 だけでいい

場面例
文頭の副詞First, ... / In conclusion, ...
If / When の節If S V, S V.
列挙A, B, and C
長い文の and / but 前S V, and S V.
○If a war happens, we cannot get food.
○First, the population is growing.
09

関係代名詞、文をつなぐ接着剤

語使うとき
who人
whichもの
thatどっちも
○people who have no food
○a country which imports food

2文を1文にまとめる道具。同じ単語が両方に出てきたら関係代名詞でつなげる。

10

not only A but also B

「AだけでなくBも」。準1の作文で点が上がる定番。
not only A but also B
○Not only adults but also children suffer.

同じ意味で both A and B も使える。

11

仮定法、現実の逆を言うとき

「もし〜なら、〜だろうに」と現実と違うことを言うときは過去形。
If S 過去形, S would + 原形
○If we had more food, no one would starve.

be動詞は人称に関係なく were。 If I were you。

12

覚えるべき つなぎ言葉

First / Second第一に / 第二に
For example例えば
Howeverしかし
Thereforeしたがって
In additionさらに
In conclusion結論として
For these reasonsこれらの理由から

どれも文頭で使う。直後にカンマ。これだけで型ができる。
